# WinGo 1M GitHub Pages Analyzer

Upload all files to a GitHub repository and enable Settings -> Pages -> Deploy from branch -> main -> root.

The page is static HTML/CSS/JS. It attempts to read public WinGo 1M history directly from the browser. If cross-origin access is blocked, it switches to demo data.

This is a statistical research interface, not a guaranteed predictor or RNG/seed extractor.
